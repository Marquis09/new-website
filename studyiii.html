MMU TV Website - Web Development & UX Case Study

Building a "CREATIVE PLATFORM" for the MMU Community to showcase and explore media projects.

Process Index: Project Overview | Challenges | Design Goals | Development Process | Key Solutions | Reflection | What I Learned

Executive Summary

  • Overview: This project allowed me to design and build a creative media platform from the ground up. My goal was to create a space where MMU students and staff could easily share, explore, and engage with video content.
  • Challenge: Building a fully responsive, intuitive website that supports diverse media formats while remaining simple enough for casual browsing.
  • Outcome: A clean, Bootstrap-powered platform with intuitive navigation, mobile-first layouts, and a streamlined sign-up flow.

Project Details

  • My Role: Web Developer, UX Designer
  • Duration: 3 Weeks
  • Tools: HTML5, CSS3, Bootstrap, Figma
  • Project Type: University Project / "COMMUNITY PLATFORM"
Visit Live MMU TV Website

📁 1. Project Overview & Introduction

The MMU TV website was created as a platform to showcase "CREATIVE PROJECTS" from Manchester Metropolitan University (MMU) students and staff. The core goal was to make it easy for users to "EXPLORE VIDEOS", sign up, and engage with the MMU community.

⚠ The Challenge: To design and build a fully functional, mobile-friendly website from scratch that could host diverse media content while maintaining an intuitive user experience for both student creators and casual viewers.
🎬 Visit the Live MMU TV Website

📁 2. Challenges & Design Goals

Key Challenges

  • Layout: Lack of a clear, modern layout for displaying diverse video content.
  • Accessibility: Ensuring the website was mobile-friendly and met accessibility standards.
  • Search: Creating a simple but functional search feature for filtering video content.
  • User Needs: Developing an intuitive user experience that caters to both students and staff.

Primary Design Objectives

  • Responsiveness: Build a responsive, mobile-first design for easy access on all devices.
  • Navigation: Develop an intuitive navigation system to quickly find and view videos.
  • Visual Appeal: Create visually appealing and engaging content sections to showcase creative work.
  • Simplicity: Design the sign-up and interaction processes for maximum simplicity.

📁 4. Final Thoughts & Reflection

This project was an exciting opportunity to apply my front-end development skills and create a user-centric website that serves the MMU community. With responsive design, accessibility, and simple navigation, the MMU TV website provides a seamless and engaging experience for users across all devices.

Reflection

Building MMU TV strengthened my confidence in designing for diverse audiences and creating layouts that balance creativity with usability. I learned how important it is to simplify interactions, especially when users are exploring media content. This project helped me refine my ability to design responsive interfaces and create clear, predictable user flows.

What I Learned

  • Clear navigation helps users explore content confidently.
  • Mobile-first layouts are essential for modern media platforms.
  • Simple search features dramatically improve content discoverability.
  • Visual consistency builds trust and improves engagement.
  • Small UX improvements can significantly enhance user satisfaction.

How This Project Helped Me Grow

MMU TV helped me bridge my front-end development skills with UX thinking. I learned how to design for real users in a community context, create layouts that support content discovery, and build responsive experiences that feel consistent across devices. It reinforced my ability to ship complete, functional projects that balance creativity with usability.
